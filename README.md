# 알바톡 (Alba-Talk) 🏪

아르바이트 매장을 위한 **업무 보고서 · 근무 일정 · 직원 소통** 웹 앱입니다.
사장님과 알바생이 한곳에서 업무를 인수인계하고, 근무표를 확인하고, 대타를 구하고, 공지를 주고받을 수 있습니다.

## 주요 기능

### 📝 업무 보고서
- 근무 종료 후 출퇴근 시간, 오늘 한 일, 특이사항, 인수인계 사항을 기록
- 다음 근무자가 인수인계 내용을 바로 확인 (강조 표시)
- 전체 보고서 / 내 보고서 필터

### 📅 근무표 (주간 / 월간)
- 주 단위 근무 일정 확인 (지난주 / 이번주 / 다음주 이동)
- **월간 캘린더 뷰**: 한 달 근무를 캘린더로 한눈에, 날짜 클릭 시 해당 주간으로 이동
- 사장님이 직원별 근무 등록·삭제
- **대타 요청**: 알바생이 자기 근무에 사유와 함께 대타 요청 → 다른 직원이 "내가 대신 근무할게요" 클릭 시 근무가 자동으로 넘어감

### 💬 게시판
- 공지사항(사장님 전용 작성)과 자유 게시판
- 글마다 댓글로 소통

### ⏰ 출퇴근 체크
- 대시보드에서 출근하기 / 퇴근하기 버튼으로 실제 근무 시간 기록
- 퇴근 후 출퇴근 시간이 자동 입력된 업무 보고서 작성으로 바로 연결

### 💰 급여 · 근무시간
- 월별 직원별 예정 근무시간(근무표 기준)과 실제 근무시간(출퇴근 기록 기준) 집계
- 예상 급여 = 실제 근무시간 × 시급 (사장님은 전체 합계, 알바생은 본인만 조회)

### 👥 직원 관리 (사장님 전용)
- 직원 등록(이름·담당·시급·PIN), 정보 수정, PIN 재설정
- 퇴사 처리(비활성화) 시 로그인·근무 배정에서 제외, 과거 기록은 유지

### 🔔 인앱 알림
- 대타 요청/수락, 새 공지, 내 글의 댓글, 근무 배정/취소 시 관련 직원에게 알림 생성
- 상단 벨 아이콘에 안 읽은 알림 수 배지, 알림 클릭 시 해당 화면으로 이동

### 🏠 대시보드
- 오늘 근무자, 내 다음 근무, 대기 중인 대타 요청, 최근 보고서·게시글을 한눈에

## 실행 방법

```bash
npm install
npm run dev
```

브라우저에서 http://localhost:3000 접속.

## 기술 스택

- **Next.js 14** (App Router, Server Actions)
- **TypeScript** + **Tailwind CSS**
- 저장소: **SQLite** (`better-sqlite3`, `data/alba.db`) — 서버 설치 없이 파일 하나로 동작
- 최초 실행 시 `data/db.json`의 시드 데이터가 SQLite로 자동 마이그레이션됩니다

## 프로젝트 구조

```
app/
  page.tsx            # 대시보드 (출퇴근 체크 포함)
  login/              # 로그인
  reports/            # 업무 보고서 목록·작성
  schedule/           # 주간 근무표 + 대타 요청 (month/: 월간 캘린더)
  board/              # 게시판 목록·상세·댓글
  pay/                # 월별 급여·근무시간
  staff/              # 직원 관리 (사장님 전용)
  notifications/      # 인앱 알림
components/Nav.tsx    # 공통 내비게이션 (알림 벨 포함)
lib/
  types.ts            # 데이터 모델
  db.ts               # SQLite 저장소 (시드 자동 마이그레이션)
  auth.ts             # 세션 → 사용자 조회
  security.ts         # PIN 해시(sha256+salt), 세션 쿠키 HMAC 서명
  actions.ts          # Server Actions (로그인, 출퇴근, 보고서, 근무, 대타, 게시글, 직원, 알림)
data/db.json          # 시드 데이터 (최초 실행 시 SQLite로 이전)
data/alba.db          # SQLite 데이터 파일 (자동 생성, git 미포함)
```

## 보안

- PIN은 salt를 붙여 SHA-256 해시로 저장합니다 (평문 저장 없음)
- 세션 쿠키는 HMAC 서명되어 위조된 쿠키는 거부됩니다
- 프로덕션에서는 `SESSION_SECRET` 환경 변수를 반드시 설정하세요
