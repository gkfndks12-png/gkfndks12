# 알바톡 (Alba-Talk) 🏪

아르바이트 매장을 위한 **업무 보고서 · 근무 일정 · 직원 소통** 웹 앱입니다.
사장님과 알바생이 한곳에서 업무를 인수인계하고, 근무표를 확인하고, 대타를 구하고, 공지를 주고받을 수 있습니다.

## 주요 기능

### 📝 업무 보고서
- 근무 종료 후 출퇴근 시간, 오늘 한 일, 특이사항, 인수인계 사항을 기록
- 다음 근무자가 인수인계 내용을 바로 확인 (강조 표시)
- 전체 보고서 / 내 보고서 필터

### 📅 주간 근무표
- 주 단위 근무 일정 확인 (지난주 / 이번주 / 다음주 이동)
- 사장님이 직원별 근무 등록·삭제
- **대타 요청**: 알바생이 자기 근무에 사유와 함께 대타 요청 → 다른 직원이 "내가 대신 근무할게요" 클릭 시 근무가 자동으로 넘어감

### 💬 게시판
- 공지사항(사장님 전용 작성)과 자유 게시판
- 글마다 댓글로 소통

### 🏠 대시보드
- 오늘 근무자, 내 다음 근무, 대기 중인 대타 요청, 최근 보고서·게시글을 한눈에

## 실행 방법

```bash
npm install
npm run dev
```

브라우저에서 http://localhost:3000 접속.

## 기술 스택

- **Next.js 14** (App Router, Server Actions)
- **TypeScript** + **Tailwind CSS**
- 저장소: `data/db.json` (JSON 파일 기반 — 별도 DB 설치 없이 바로 실행)

## 프로젝트 구조

```
app/
  page.tsx            # 대시보드
  login/              # 로그인
  reports/            # 업무 보고서 목록·작성
  schedule/           # 주간 근무표 + 대타 요청
  board/              # 게시판 목록·상세·댓글
components/Nav.tsx    # 공통 내비게이션
lib/
  types.ts            # 데이터 모델
  db.ts               # JSON 파일 저장소
  auth.ts             # 쿠키 기반 세션
  actions.ts          # Server Actions (로그인, 보고서, 근무, 대타, 게시글)
data/db.json          # 시드 데이터 포함 데이터 파일
```

## 참고 (프로덕션 전 개선 필요)

현재는 빠른 시작을 위한 MVP 구조입니다. 실제 서비스 전에는 다음을 권장합니다.

- JSON 파일 → 실제 데이터베이스(PostgreSQL, SQLite 등)로 교체
- PIN 평문 저장 → 해시 처리, 세션 쿠키 서명
- 직원 초대/가입 흐름, 푸시 알림(대타 요청·공지) 추가
